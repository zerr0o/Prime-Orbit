# Prime Orbit v0.1.17 — Faster sessions and reliable controls

Prime Orbit 0.1.17 focuses on long-running Prime Agent sessions: queued instructions stay consistent with the persisted transcript, completed Goals can be managed reliably, and typing remains responsive even when a conversation contains thousands of messages.

## Highlights

- Accepted Steer and follow-up messages are repaired from Prime Agent's authoritative history when a fast queue transition or navigation causes Orbit to miss the live user event. Already delivered rows no longer remain as editable queue entries.
- Goal actions wait for the matching `goal_update` instead of treating an IPC write as completion. The operation remains attached to its conversation across navigation, and a final state refresh cannot restore an older Goal snapshot.
- Completed Goals remain visible as session history but no longer inflate the active Goal badge. **Clear** and **New goal** remain available with real pending and error feedback.
- Long transcripts are isolated from persisted draft updates. Historical Markdown, tools, and attachments are reused while typing, and streaming refreshes only the active turn.
- Python execution groups start collapsed, the context ring opens a detailed usage panel, and Session now separates runtime state, files, Goal, subagents, and monitoring.
- Conversation context actions are available from Home, Runs, and navigation surfaces. Selecting a project reopens its most recently updated active conversation.
- Compact and Refine use an exclusive native admission fence across windows, with explicit lifecycle feedback rather than duplicate or misleading actions.
- Markdown web links and project files use explicit handlers, paths outside the project remain blocked, and Ctrl/Cmd+P can no longer open the WebView print dialog accidentally.

## Performance note

Before this release, persisting one composer keystroke could make a 3,000-message transcript refilter, regroup, and parse its Markdown again; the measured render path reached roughly 1.87 seconds. The transcript now uses an O(1) presentation boundary for draft-only updates, so those keystrokes render no historical Markdown. Streaming appends reuse prior turns and update only the final affected turn.

## Validation

- Targeted tests cover fast queue consumption, terminal history repair, duplicate text and attachment identity, Goal lifecycle/navigation races, stale state snapshots, and long-transcript memoization.
- The signed Windows workflow rechecks the frontend tests and production build, Rust tests, formatting, strict Clippy, Rust 1.88 compatibility, updater signatures, uploaded asset digests, and installer checksums before leaving a draft for review.

Prime Orbit is an independent community client built around Prime Agent. It preserves Prime Agent as the authority for session state, queues, Goals, model execution, and persisted history.
