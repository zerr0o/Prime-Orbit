# Prime Orbit v0.1.14 — Signed in-app updates

Prime Orbit 0.1.14 establishes the signed stable update channel and adds an explicit, session-aware update experience to the desktop application.

## Highlights

- Added a native update panel in **Settings > About** with manual checks, release notes, published dates, download progress, retryable failures, and separate download and install confirmation.
- Added optional startup checks. Automatic checks only look for a release; they never download or install one without confirmation.
- Synchronized updater state across every Prime Orbit window, coalescing concurrent checks and downloads while rejecting stale responses.
- Added bounded check and download timeouts, a 24-hour automatic-check window, failure backoff, and retry support without inventing a successful or restart-ready state.
- Kept downloaded updater bytes in native memory and exposed **Restart and update** only after the signed Tauri download completes.
- Added an installation fence across all windows. If Prime Agent sessions are open, Prime Orbit explains what will stop and requires a second confirmation before interrupting active work.
- Added a dismissible update notification that opens the real updater panel instead of downloading in the background.

## Signed release channel

- Added the stable public manifest at `https://github.com/zerr0o/Prime-Orbit/releases/latest/download/latest.json`.
- Added mandatory Tauri signatures for both NSIS and MSI updater payloads, verified against the public key embedded in Prime Orbit.
- Added a draft-first GitHub release workflow with strict version synchronization, pinned actions, versioned notes, installer checksums, and final asset and signature gates.
- Added `SHA256SUMS-v0.1.14.txt` for the downloadable EXE and MSI installers.

Each updater payload also has a companion `.sig` asset. These Tauri updater signatures establish update authenticity; they are not Windows Authenticode signatures.

## Upgrade instructions

### From Prime Orbit 0.1.13 or earlier

1. Close every Prime Orbit window.
2. Download and install Prime Orbit 0.1.14 manually using the recommended `.exe` installer.
3. Reopen your projects. Persistent conversations and saved Prime Agent sessions are preserved.

Prime Orbit 0.1.13 does not contain the updater public key or client and therefore cannot discover or install 0.1.14 itself. Version 0.1.14 is the one-time trust bootstrap for future signed updates.

### After installing 0.1.14

Future stable releases signed by the same updater key can be checked, downloaded, and installed from **Settings > About**. Startup checks can be disabled in that same **About** section and never download or install automatically.

## Important notes

- Installing an update restarts Prime Orbit. If Prime Agent sessions are still open, choose **Later** to let them finish or explicitly confirm **Install anyway**.
- Forcing installation stops open Prime Agent sessions. Running turns are interrupted, and queued files or attachments that have not been delivered may be lost; saved sessions remain recoverable.
- The Windows installers are not Authenticode-signed and may still trigger a SmartScreen unknown-publisher warning. Verify `SHA256SUMS-v0.1.14.txt` for manual downloads.
- The first updater implementation exposes one honest channel: stable. Drafts and prereleases are not offered to the application.

## Validation

- 74 frontend unit tests and TypeScript production build.
- Complete Rust test suite, formatting, strict Clippy, and Rust 1.88 MSRV check.
- Native updater tests cover automatic-check coalescing, failure backoff, multi-window revision ordering, download progress, retry behavior, installation fencing, and bounded release metadata.
- The release gate verifies both updater artifacts and their `.sig` files against the embedded public key before leaving the GitHub release as a draft for manual review.

Prime Orbit is an independent community client built around Prime Agent. It does not weaken Prime Agent's permission boundary or claim operating-system sandboxing.
