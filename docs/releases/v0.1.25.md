# Prime Orbit v0.1.25 — External links and queue reliability (beta)

Prime Orbit 0.1.25 fixes external links inside conversations and hardens the Steer / Follow-up queue against stale rows, based on a line-by-line re-evaluation of Prime Agent v0.8.0's own queue semantics.

## External links open again

- Clicking a link in a conversation no longer reports `Command plugin:opener|open_url not allowed by ACL`. The desktop capability now enables the opener command with an explicit scope limited to `mailto:`, `tel:`, `http://` and `https://` URLs.
- When the native opener is unavailable, http(s) links fall back to the system browser exactly like the context menu and release notes already did.

## Queue reconciliation aligned on Prime Agent

- Delivered instructions longer than 160 characters are now recognized: Prime Agent compacts the running action's label, and the previous exact-text comparison never matched, leaving long prompts stuck in the tray for good.
- Rows whose delivery completed while another conversation or window was focused are repaired as soon as the conversation becomes visible again, and on every authoritative state refresh — the dedicated "refresh state" action is no longer required to see a delivered instruction land in the transcript.
- A regression test locks the truncated-label behaviour, mirroring Prime Agent's `compactRlmText`.
