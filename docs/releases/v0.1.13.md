# Prime Orbit v0.1.13 — Native recovery and secure attachments

Prime Orbit 0.1.13 strengthens the desktop integration with Prime Agent through native resource reload, safer session recovery, path-free document attachments, and more reliable conversation ordering.

## Highlights

- Added Prime Agent's real `/reload` operation for settings, skills, extensions, prompts, and MCP resources without creating a model turn or restarting the session.
- Added an emergency restart for one conversation, with graceful daemon handoff and session-lease protection against duplicate workers.
- Added a native **Save As** dialog for HTML exports. Exports remain attached to their originating conversation while navigating elsewhere.
- Extended opaque native attachment handles to every document and image selected, pasted, or dropped into the composer. Original filesystem paths are never exposed to the renderer or transcript.
- Preserved unsent attachments per conversation and restored safe document cards from Prime Agent history and queued messages.
- Fixed late queue snapshots and history responses that could place a user message after its assistant reply.
- Hidden Prime Agent's internal IPython state-restoration envelope from the visible transcript.
- Reworked Ollama health detection to probe the configured server through its native `/api/tags` endpoint with bounded timeouts and chunked-response support.

## Upgrade instructions

1. Close every Prime Orbit window.
2. Install Prime Orbit 0.1.13 using the recommended `.exe` installer.
3. Reopen your projects; persistent conversations and Prime Agent sessions are preserved.

## Important notes

- **Refresh state**, **Reload resources**, and **Emergency restart** are separate operations.
- Resource reload requires a source or managed Prime Agent installation and an idle active daemon session. It is unavailable with an unsupported system executable.
- Emergency restart preserves persistent history but cancels the current run and any undelivered queued messages for that conversation.
- The installers are not yet code-signed and may trigger a Windows SmartScreen warning. Verify the SHA-256 values above before installation.
