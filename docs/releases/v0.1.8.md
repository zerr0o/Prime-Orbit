# Prime Orbit v0.1.8 — First public preview

Prime Orbit brings Prime Agent into a native, project-oriented desktop workspace. Organize local projects and persistent conversations, follow tools and sub-agents in real time, attach files and images, configure models and MCP integrations, and resume long-running work without managing the CLI manually.

## Highlights

- Project-based workspace with persistent conversations
- Stable manual project and conversation ordering with drag and drop
- Streaming responses, file and image attachments, models, reasoning levels, and supervision profiles
- Activity inspector for tools, sub-agents, context, Git changes, and session details
- Consolidated Python execution groups that keep long conversations readable
- Lazy history loading: only the conversation you open is restored
- Read-only transcript fallback when the Prime Agent runtime cannot restore a session
- Model provider and HTTP MCP management without exposing secrets to the renderer
- Managed Prime Agent detection, installation, and repair
- Multiple windows backed by shared agent processes
- Complete English and French interface

## Reliability improvements

- Safely recovers genuinely orphaned Prime Agent session leases on Windows
- Preserves live and uncertain session locks
- Prevents two Prime Orbit conversations from opening the same session concurrently
- Avoids duplicate conversation creation and repeated activity events
- Keeps the selected conversation unchanged when expanding another project
- Improves startup responsiveness and on-demand conversation loading
- Fixes click-outside menus, contextual menus, language switching, and conversation supervision controls

## Before installing

- This release provides Windows x64 binaries.
- Prime Orbit requires Prime Agent. An existing installation can be detected, or Prime Orbit can prepare a managed installation from the official repository.
- Authentication and OAuth flows are completed through Prime Agent's official terminal interface.
- Prime Agent is not a sandbox. Its tools run with your user account permissions.
- These preview installers are not code-signed and may trigger a Windows SmartScreen warning. Verify the SHA-256 value before running them.

Prime Orbit is an independent desktop client built around Prime Agent's public RPC mode. Prime Agent remains the execution engine and owns the session transcripts.
