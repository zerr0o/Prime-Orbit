# Prime Orbit v0.1.15 — Clearer turns and reliable compaction

Prime Orbit 0.1.15 is the first signed update delivered through the in-app channel introduced in 0.1.14. It makes long Prime Agent runs easier to read and fixes misleading feedback during context compaction.

## Highlights

- Consecutive Prime Agent text, Python executions, and other tool activity now share one visual turn with a single avatar and header.
- Text and tools remain in their exact causal order; streaming, tool details, errors, attachments, copy, retry, fork, timing, and token metadata remain available.
- User and system messages remain strict visual boundaries between turns.
- Context compaction now has a persistent in-progress state driven by Prime Agent's real `compaction_start` and `compaction_end` events.
- The legacy 30-second daemon acknowledgement timeout is treated as pending rather than as a failed session; the compact operation can finish normally in the background.
- Messages sent while compaction runs enter Prime Agent's real follow-up queue and are delivered after compaction.
- A native multi-window fence prevents duplicate compact operations without blocking state refreshes or queued prompts.
- On completion, Prime Orbit reloads the authoritative transcript and refreshes context statistics instead of leaving stale percentages visible.

## Update test

Version 0.1.14 can discover this release through **Settings > About**:

1. Select **Check for updates**.
2. Download version 0.1.15.
3. Choose **Restart and update** when open Prime Agent sessions are ready to stop.
4. Reopen the same conversation and confirm that the version shown in **About** is 0.1.15.

The updater never downloads or installs automatically. Prime Agent sessions and queued work are only stopped after explicit installation confirmation.

## Validation

- 83 frontend unit tests and TypeScript production build.
- 128 Rust tests, formatting, strict Clippy, and direct multi-window compaction admission tests.
- Release manifest, updater payload, signature, asset digest, and checksum verification in the signed Windows workflow.

Prime Orbit is an independent community client built around Prime Agent. It does not weaken Prime Agent's permission boundary or claim operating-system sandboxing.
