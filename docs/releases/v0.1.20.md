# Prime Orbit v0.1.20 — Desktop tray and a focused session reader

Prime Orbit 0.1.20 keeps ongoing work close at hand with native Windows tray controls and makes session memories and refinements comfortable to read without leaving the application.

## Native Windows tray and predictable closing

- Prime Orbit now has a native tray menu with direct **Open Prime Orbit** and **Quit** actions.
- Closing the main window presents a clear integrated choice between minimizing to the notification area and quitting the application.
- **Don't ask again** remembers the selected action, and the behavior can be changed at any time in **Settings > General**.
- The close dialog uses its two destination cards as the actions, keeps keyboard focus contained, and matches the application's existing surfaces.
- A remembered quit flushes current workspace state first, while tray labels follow the selected application language.

## A dedicated memory and refinement reader

- Selecting a memory or refinement card opens a large in-app reader with rendered Markdown and a comfortable line length.
- The reader reuses the entry's original Memory or Refinement icon, color, title, scope, timestamp, and safe public metadata.
- Previous and next controls make it easy to move through the current list; arrow-key navigation and Escape are supported.
- **Copy** includes only public fields supplied by Prime Agent.
- Existing actions to open the real file, reveal its folder, delete a memory, or roll back a refinement remain available in the reader and retain their integrated confirmation dialogs.

## Validation

- Frontend coverage includes remembered close behavior, native tray labels, modal focus, reader navigation, bounded public copy output, file and folder actions, and destructive confirmations.
- Native coverage validates window-close interception, tray activation and commands, preference persistence, and workspace flushing before quit.
- The signed Windows workflow rechecks frontend tests and the production build, Rust tests, formatting, strict Clippy, Rust 1.88 compatibility, updater signatures, uploaded asset digests, and installer checksums before publication.

Prime Orbit is an independent community client built around Prime Agent. It preserves Prime Agent as the authority for session state, queues, Goals, model execution, and persisted history.
