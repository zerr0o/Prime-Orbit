# Prime Orbit v0.1.21 — Prime Agent 0.8 compatibility

Prime Orbit 0.1.21 upgrades its managed runtime to the official Prime Agent 0.8.0 release and gives the new durable refinement outcomes a safe, readable home in the conversation.

## Managed Prime Agent 0.8.0 runtime

- Managed installation is pinned to the official `v0.8.0` tag and exact verified commit `8d7deeab5861bf9d77bde3d8511046a5c799818d`.
- The runtime is still prepared side by side and activated only after its version and build are verified, so a failed upgrade cannot replace the working generation.
- Prime Agent 0.8 includes more reliable cold IPython startup and MCP shutdown, queued ACP follow-ups, descendant-aware Goals, and durable refinement outcome messages.

## MCP migration

- Prime Agent 0.8 executes custom `mcpServers` from global user settings. Prime Orbit therefore creates and edits only global HTTP servers.
- Existing project-scoped entries remain visible as legacy configuration so they can be reviewed and deleted without a silent migration or conflict.
- Linear and Notion remain protected built-ins and cannot be overridden by a custom entry with the same name.
- Generic MCP OAuth credentials created by earlier Prime Agent versions may need to be rebound with `/mcp login <server>` because older credentials did not include endpoint identity.

## Durable refinement cards

- A completed refinement now appears as one compact, expandable card in live and restored conversations.
- The card shows its session/global scope, public summary, applied edit count, and bounded per-edit status.
- Prime Orbit strips private harness paths, rationale, metadata, and before/after snapshots in the native bridge before the event reaches the WebView.
- Duplicate `message_start` and `message_end` delivery is collapsed by the canonical refinement id.

## Validation

- Frontend coverage validates safe typed refinement cards and live/historical deduplication; native coverage enforces the Prime Agent 0.8 MCP scope boundary.
- Native coverage validates the managed runtime pin and removes private refinement fields from both daemon events and session history.
- The official Prime Agent 0.8 checkout is built and invoked from outside its repository before the signed Windows release is published.

Prime Orbit is an independent community client built around Prime Agent. Prime Agent remains the authority for sessions, queues, Goals, model execution, MCP execution, and persisted history.
