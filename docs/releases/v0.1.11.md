# Prime Orbit v0.1.11 — Git workflow and diff inspector

Prime Orbit 0.1.11 turns the Changes inspector into a practical Git workflow. It reports real per-file statistics, opens bounded diffs directly in the session inspector, and prepares safe Prime Agent instructions for committing, pushing, or publishing a release.

## Highlights

- Made **Changes** the first and default inspector tab.
- Replaced placeholder `+0 -0` values with real additions and deletions from Git.
- Added expandable per-file diff previews with readable added, removed, header, and hunk styling.
- Added explicit handling for renamed, deleted, untracked, binary, metadata-only, truncated, loading, and error states.
- Added **Commit + push** and **Publish release** buttons that prepare a detailed instruction in the composer without sending it.
- Added a confirmation dialog before replacing an existing composer draft.
- Hardened Git paths and bounded all diff and untracked-file reads.

## Upgrade instructions

1. Close every Prime Orbit window.
2. Install Prime Orbit 0.1.11 using the recommended `.exe` installer.
3. Reopen your projects; existing conversations and Prime Agent sessions are preserved.

The installers are not yet code-signed and may trigger a Windows SmartScreen warning. Verify the SHA-256 values above before running a downloaded installer.

## Validation

- Frontend unit tests and TypeScript production build.
- Full Rust test suite, strict Clippy, Rust 1.88 MSRV check, formatting, and diff validation.
- Windows Tauri release build with NSIS and MSI installers.

Prime Orbit is an independent community client built around Prime Agent. The Git inspector is read-only; commit, push, tag, and release mutations remain explicit Prime Agent tasks.
