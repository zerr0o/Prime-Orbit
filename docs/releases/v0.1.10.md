# Prime Orbit v0.1.10 — Reliability and security hardening

Prime Orbit 0.1.10 consolidates the audit fixes and the latest desktop reliability improvements. It stops redundant workspace saves, strengthens attachment and configuration boundaries, improves multi-window runtime behavior, and adds a complete project context workflow.

## Highlights

- Fixed the workspace save loop that could repeatedly rewrite an unchanged state file and display a persistent “changes could not be saved” notification.
- Added a native idempotency guard so identical state writes do not touch the file, increment its revision, or emit another synchronization event.
- Replaced embedded image payloads with bounded, window-scoped native handles; explicitly selected documents outside the project remain supported as path references.
- Hardened MCP and model configuration writes, lock recovery, secret redaction, runtime diagnostics, and extension request routing.
- Added project right-click actions for pinning, renaming, opening the folder directly, archiving conversations, and confirmed deletion.
- Improved transactional prompt delivery, repeated follow-ups, retry feedback, and selected-session history recovery.

## Upgrade instructions

1. Close every Prime Orbit window.
2. Install Prime Orbit 0.1.10 using the recommended `.exe` installer.
3. Reopen your projects; existing conversations and Prime Agent sessions are preserved.
4. If Prime Agent itself is reported unhealthy, open **Settings → Prime Agent** and run **Managed installation** once.

The installers are not yet code-signed and may trigger a Windows SmartScreen warning. Verify the SHA-256 values above before running a downloaded installer.
