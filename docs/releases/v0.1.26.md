# Prime Orbit v0.1.26 — Native Plan mode (beta)

Prime Orbit 0.1.26 adds a native, conversation-scoped Plan workflow. Prime Agent can inspect a project, ask blocking questions, submit a reviewable Markdown plan, and continue directly into implementation only after explicit approval.

## Plan safely before implementation

- Select **Plan** beside the composer or use `/plan`. New conversations still start in **Normal** mode.
- The Plan runtime starts with only three embedded tools: bounded project inspection, interactive questions, and final plan submission. Discovered extensions, skills, prompt templates, shell, MCP, Python, RLM/delegation, and every other tool remain unavailable.
- A second deny-by-default gate blocks any tool outside that exact allowlist, even if runtime state attempts to reactivate it.
- Attachments are disabled in Plan mode because they would bypass the isolated inspection path.

## Questions and review

- Prime Agent questions pause the turn until you choose a structured answer, enter a custom response, or cancel.
- The final Markdown document appears directly in the conversation.
- **Revise** asks what should change and returns that feedback to the planning agent without saving the rejected draft.
- **Keep** writes the accepted document atomically under `.prime/plans/` and exits Plan mode.
- **Apply plan** saves it, restarts the same Prime Agent session with the Normal runtime, and immediately uses the approved Markdown as the implementation source of truth.

## Durable and multi-window

- Pending questions survive WebView reloads through the native request cache.
- Apply/Keep decisions are persisted before Orbit consumes the blocking response. Recovery uses staged state and a stable canonical transcript marker to avoid silent loss and blind duplicate implementation prompts.
- Only the current interactive window may answer a pending extension dialog or change the runtime mode. Native response claims prevent two windows from answering the same request.
- Kept plans remain visible after history reload, including documents above the generic diagnostic truncation limit.

## Native attention and safe storage

- Windows shows a generic, privacy-safe notification with the default system sound only when no Prime Orbit WebView is visible and focused.
- If a blocking request arrives without a surviving renderer owner, the native RPC reader raises the notification itself.
- Plan paths and documents are bounded. Reads verify canonical containment and the opened file identity before returning content. Saves are attested to the active Plan runtime and project, reject links/reparse points, and publish new collision candidates without replacing an existing file.

## Validation

Validated with 229 frontend tests, 195 native tests, TypeScript, the production Vite build, strict Clippy, Rust 1.88, 27 Plan state/protocol regressions, and a 47-check strict harness against the embedded Prime Agent v0.8.0 extension contract.
