# Prime Orbit v0.1.12 — Prime Agent fidelity and real queues

Prime Orbit 0.1.12 moves closer to a complete desktop interface for Prime Agent. It exposes real queue, supervision, session, and branching capabilities while keeping background and multi-window work attached to the same native runtime.

## Highlights

- Replaced UI-only supervision controls with Prime Agent's real steering and follow-up modes.
- Added a discreet live instruction queue with native editing and deletion for daemon-backed messages.
- Fixed consecutive queued turns so each user message appears beside its own assistant response in authoritative Prime Agent order.
- Added heartbeat and scheduled-job visibility with pause, resume, stop, and cancellation controls.
- Added lazy discovery of top-level sessions created by the classic Prime Agent terminal.
- Kept running sessions alive while navigating between conversations and application pages.
- Added real session branching from a selected turn, session cloning, and synchronized session renaming.
- Added bounded native image thumbnails in the composer, transcript, and Session inspector.
- Rehydrated image previews and session history without exposing original image bytes or local paths to the renderer.

## Upgrade instructions

1. Close every Prime Orbit window.
2. Install Prime Orbit 0.1.12 using the recommended `.exe` installer.
3. Reopen your projects; existing conversations and Prime Agent sessions are preserved.

The installers are not yet code-signed and may trigger a Windows SmartScreen warning. Verify the SHA-256 values above before running a downloaded installer.
