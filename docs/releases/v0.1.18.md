# Prime Orbit v0.1.18 — Reliable recovery and cleaner conversations

Prime Orbit 0.1.18 improves recovery after long agent runs and makes collaboration and everyday editing easier to read.

## Reliable runtime state

- Prime Orbit now reconciles its terminal UI state with the daemon's authoritative session state when a final lifecycle event is missed.
- Orphaned Python activity cards are completed, and an already-finished run no longer forces the next prompt into the follow-up queue.
- Idle snapshots are accepted only when the daemon is truly quiescent and no newer prompt or agent lifecycle has started.
- Conversation history is reloaded after recovery when a first response was discarded during the reconnection race.

## Cleaner agent collaboration

- Agent-to-agent messages appear as compact, expandable notices instead of raw transport envelopes.
- Live and restored notices are validated, bounded, and deduplicated before display.
- Private runtime identifiers and protocol bookkeeping stay outside the conversation UI while the useful Markdown body remains available on expansion.

## Composer and interface

- Rename fields keep focus during background workspace refreshes and return focus to their opener when dialogs close.
- Pressing **Enter** continues Markdown dash and numbered lists; pressing Enter on an empty item leaves the list.
- The composer delegates right-click handling to native WebView2 spelling suggestions when the corresponding Windows dictionary is available.
- Update notes in **Settings > About** now render safe structured Markdown, including headings, lists, tables, links, and code.
- The global new-conversation button is temporarily hidden; conversation creation remains available from the workspace sidebar.

## Validation

- Frontend coverage includes terminal-state recovery, stale-snapshot rejection, inter-agent notice sanitization, modal focus stability, Markdown list editing, spelling-menu delegation, and safe release-note rendering.
- Native coverage validates the IPC sanitization boundary for live and restored inter-agent messages.
- The signed Windows workflow rechecks frontend tests and the production build, Rust tests, formatting, strict Clippy, Rust 1.88 compatibility, updater signatures, uploaded asset digests, and installer checksums before publication.

Prime Orbit is an independent community client built around Prime Agent. It preserves Prime Agent as the authority for session state, queues, Goals, model execution, and persisted history.
